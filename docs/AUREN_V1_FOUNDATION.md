# AUREN V1 Foundation

Core product shell now has explicit boundaries for:
- Home / For You
- Discover
- Messenger
- Personal AI
- Memory
- Action Center
- AI Gateway

Principles:
1. AI is an orchestration layer, not a single screen.
2. User data is user-controlled.
3. Sensitive actions require explicit approval.
4. Provider secrets stay server-side.
5. Social, entertainment, discovery, work and opportunity can coexist without forcing one path.

Next production layers: authentication upgrade, profile/social graph, notifications, media storage, offline cache, real backend gateway, and moderation/trust services.
