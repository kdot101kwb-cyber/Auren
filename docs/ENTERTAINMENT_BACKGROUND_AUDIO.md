# AUREN Entertainment — Background Audio

## Current state
AUREN Music uses `just_audio` and the persistent music controller. Queue, history, and Continue Listening are persisted locally.

## Android background-playback integration
The repository currently does not contain the generated Flutter Android host project (`android/`) in GitHub. Background playback with lock-screen/media-notification controls requires the Android host configuration generated by Flutter plus the audio background service configuration.

When the Android host is added, integrate the audio handler around the existing `AurenMusicPlayerController` rather than creating a second player.

Required capabilities:
- background playback
- Android media notification
- lock-screen play/pause
- previous/next
- seek
- media metadata
- automatic queue advancement
- notification lifecycle tied to playback

## Safe integration rule
Do not maintain two independent `AudioPlayer` instances. The background handler and UI must share one playback source/state.

## Current fallback
The app continues to support foreground playback, Mini Player, Queue, History, and Continue Listening without requiring native Android files.
