# AUREN Product Foundation

## Core principle
AUREN adapts to the user, not the user to the app.

## Primary entry paths
1. For You — personalized Smart Timeline
2. Messenger — communication
3. Personal AI — goals, questions and actions
4. Opportunities — work, business, talent and learning
5. Discover — entertainment, culture, places and communities

## MVP direction
The first implementation should prove one connected loop:
**User → Conversation → Personal AI context → Action → Opportunity/Content → Return to AUREN**.

## Guardrails
Sensitive actions require explicit user approval. Personal AI memory must have user controls. AI providers must be abstracted behind an AUREN AI Gateway.
