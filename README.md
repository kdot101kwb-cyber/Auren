# AUREN

**AUREN — Together, We Build.**

Connect. Create. Achieve.

## Vision
AUREN is an AI-native social, opportunity, communication and everyday-life platform. It adapts to the user, not the other way around.

## Current foundation
- Android-first Flutter architecture
- Firebase-ready backend boundary
- AI Gateway boundary for model routing
- Messenger + Personal AI as the first product track
- Offline/low-data and trust/safety as core constraints

## Status
Repository initialized. Product implementation starts from the foundation in this repository.

## Agent platform
The repository now contains the foundations for agent identity, credentials, AUREN-A2A, marketplace discovery, execution idempotency, capability grants, wallet reservation and agent trust. Trusted backend deployment is required before financial or cross-agent operations are production-ready.


## Entertainment production
The app now includes an AUREN Production Studio foundation for Shorts, films and series episodes. It provides a Firestore-backed production queue, Production History, cancel/retry controls, engine selection and a provider-neutral worker contract. Long-form jobs are designed to be split into scenes/shots and processed by server-side GPU workers using engines such as SkyReels and LTX-2; MoneyPrinterTurbo remains the short-form automation worker.
