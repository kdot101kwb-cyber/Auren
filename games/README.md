# AUREN Games

## Unified Game Platform

AUREN Games is a shared game platform for lightweight mobile and web games. Games use a common identity, profile, progression, achievements, statistics, input, audio, save, and results architecture.

### 10-step rollout

1. Game Hub and shared runtime
2. Ludo, Dominoes, UNO
3. Football, Basketball
4. Boxing and Fighting
5. Racing
6. Crime Files and Mystery
7. Wars and Samurai
8. Arcade/Casual pack
9. Gaming Profile, XP, achievements, rankings and match history
10. Godot validation, Android packaging, performance QA and release gates

### Current game

- `lost_world_3d/` — playable procedural 3D vertical slice

New games should reuse the shared contracts rather than create isolated progression or profile systems.
